**QGroundControl**（QGC）是一款面向无人机的地面站（GCS）软件，为任何支持 *MAVLink* 协议的无人机提供完整的飞行控制与任务规划能力，包括 *PX4* 与 *ArduPilot* 平台。

## 功能特性

- **任务规划** —— 规划、编辑并执行自主航点、测绘与结构扫描任务。
- **实时飞行视图** —— 地图、仪表与完整遥测数据的实时飞行显示。
- **飞行器设置** —— 提供传感器校准、遥控器、飞行模式与电源配置的引导向导。
- **参数调优** —— 通过 Fact 系统查看并修改飞行器的每一个参数。
- **视频流** —— 基于 GStreamer 的 UDP RTP / RTSP 视频，并支持在飞控界面中录像。
- **多飞行器** —— 同时连接并监控多架飞行器。
- **MAVLink 工具** —— 内置 MAVLink 检查器、控制台、日志下载与分析。
- **跨平台** —— 一套代码即可支持 Windows、macOS、Linux、Android 与 iOS。
